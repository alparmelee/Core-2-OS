Part A

Application issues

Most 3.2 fixes reuse the same short toolkit. Memorize the chips once; each symptom below only adds what is unique.

Shared toolkit

The exam writes these in slightly different sentences. Treat them as one action each — the 3.5 PBQ uses these exact labels.

Almost every app / OS ticket

  • Restart the device
  • Update the app
  • Reinstall the app
  • Update the OS
  • Check storage space
  • Check network / try another network
  • Check payment method
  • Check MDM policy

Then only the extras

  • Force close the app
  • Toggle the radio off and on
  • Check battery health
  • Hardware / crash logs — contact support

Application fails to launch

  • Restart the device
  • Update the app
  • Reinstall the app

Application fails to close / crashes

iOS: slide it off the app list. Android: Force Stop in Settings, then reopen.

  • Force close the app
  • Restart the device
  • Update the app
  • Reinstall the app
  • Review crash logs / contact support

Application fails to update

  • Update the app
  • Check payment method
  • Check network / try another network
  • Check storage space
  • Restart the device
  • Check MDM policy
  • Same blockers as a failed install, plus restart

Application fails to install

  • Check storage space
  • Check payment method
  • Check network / try another network
  • Check MDM policy

Slow to respond

  • Restart the device
  • Update the app
  • Update the OS
Part B

OS and device health

Operating system updates, power problems, and unexpected reboots.

OS fails to update

  • Check storage space
  • Check network / try another network
  • Restart the device

Battery life issues

  • Airplane Mode (poor coverage)
  • Turn off unused radios (Wi-Fi, Bluetooth, GPS)
  • Check battery health
  • Replace the battery

Random reboots

  • Update the OS
  • Update the app
  • Review crash logs / contact support
  • Check battery health
Part C

Connectivity and display

Wireless radios, proximity features, and screen orientation.

Connectivity issues — Wi-Fi

  • Toggle the radio off and on (Wi-Fi / Bluetooth / NFC)
  • Verify Wi-Fi password / AP settings
  • Check network / try another network
  • Restart the device

Connectivity issues — Bluetooth

  • Toggle the radio off and on (Wi-Fi / Bluetooth / NFC)
  • Restart the device
  • AirDrop: Bluetooth + Wi-Fi on; move closer

Connectivity issues — Near-field communication (NFC)

  • Toggle the radio off and on (Wi-Fi / Bluetooth / NFC)
  • Restart the device
  • Update linked payment cards

Screen does not autorotate

  • Check orientation lock
  • Close and reopen the app
  • Restart the device
  • Hardware failure — contact support
