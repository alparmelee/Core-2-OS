Internet Options

Control Panel › Internet Options

Control Panel ›  Network and Sharing Center > Internet Options

Windows Run dialog box > inetcpl.cpl

Configure browser proxy settings, security zones, certificate management, privacy settings, and temporary internet files.

  • General: Delete browsing history, temporary files, cookies, cache.

  • Security: Security zones (Internet vs. Local Intranet vs. Trusted Sites) and custom security levels.
    Privacy: Pop-up Blocker settings, location tracking permissions, and basic cookie blocking behaviors.
    Content: Manages digital certificates, AutoComplete preferences for forms/passwords, and RSS feed subscriptions.

  • Connections: Proxy settings, LAN settings, and VPN setups.
    Programs: Controls default browser selections, enables or disables browser add-ons and extensions, and specifies default web editors.

  • Advanced: Resetting Internet Explorer/system web settings back to defaults, enabling/disabling TLS versions.

    Lid actions and Fast Startup

    Power Options › System Settings

    Choose what closing the lid does — Do Nothing, Sleep, Hibernate, or Shut Down.

    Turn on fast startup: a hybrid boot state that saves the Windows kernel session state to disk during shutdown to reduce boot times.

    Hibernate:

    Saves the system state
    Resumes full system operation more slowly than it does when waking from sleep mode
    Turns the computer off after saving the system state to disk

    Sleep Mode:

  • Requires a small amount of power to maintain system memory

    Resumes full system operation faster than it does when recovering from hibernation mode

    Keeps the system state


    • Sleep states and USB selective suspend

    Power Options › Sleep States / Advanced Settings

    Sleep/suspend keeps RAM powered while placing CPU and components into low-power states for fast instant-on resumption.

    Standby is a legacy low-power state that preserves the system session in memory while powering down non-essential hardware.

    Hibernate saves active system memory to hiberfil.sys and powers off the system for long downtime.

    USB selective suspend suspends power to individual USB ports when idle without affecting other USB devices.
