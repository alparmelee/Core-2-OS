Part A

Crashes and boot failures

Problems first — then the fixes indented underneath each one.

Problem

Blue screen of death (BSOD)

Stop error

Windows stops with a blue screen when bad hardware, bad drivers, or a failing app prevents the OS from continuing. Note the stop code / QR details for targeting the right fix.

Fix · BSOD

Last Known Good Configuration

Boot into the last successful startup registry and driver set after a bad driver or config change.

Fix · BSOD

System Restore

Roll system files, drivers, and settings back to a restore point without wiping personal documents.

Fix · BSOD

Roll back drivers

In Device Manager, undo a recently installed driver that started the crashes.

Fix · BSOD

Safe Mode

Boot with only essential drivers/services so you can remove bad software or roll back drivers that block a normal start.

Fix · BSOD

Reseat components

Power down and reseat RAM, GPU, and power connectors — loose hardware often looks like a software stop error.

Fix · BSOD

Hardware diagnostics

Run UEFI/BIOS or vendor tools to test CPU and RAM when stop codes point at memory or kernel faults.

Problem

Boot issues

Windows fails to start normally — missing OS/bootloader, dual-boot conflicts, or the system only reaches Safe Mode. Non-bootable media can also block startup.

Fix · Boot issues

Remove non-bootable media

Unplug USB installers, external drives, and optical discs that the firmware may try to boot before the OS disk.

Fix · Boot issues

Startup Repair

Use the automated WinRE tool first when Windows fails to start or only boots into Safe Mode.

Fix · Boot issues

bootrec /rebuildbcd

From the Recovery Console, rebuild the Boot Configuration Database when Startup Repair is not enough.

Problem

“No OS found”

The firmware or bootloader cannot find a bootable OS — often bootloader corruption, dual-boot overwrites, or missing boot files.

Fix · No OS found

Unplug non-bootable drives

Disconnect extra media and secondary disks so firmware boots the correct Windows volume.

Fix · No OS found

Startup Repair

Let WinRE repair missing or damaged boot files that trigger a “No OS found” message.

Fix · No OS found

bootrec /rebuildbcd

Manually rebuild the BCD from the Recovery Console command prompt if Startup Repair does not restore boot.

Part B

Performance and stability

Slowdowns, unexpected shutdowns, memory pressure, and clock sync problems.

Problem

Degraded performance

The PC feels slow or unresponsive — apps lag, disk thrashing is high, or tasks take longer than normal.

Fix · Degraded performance

Task Manager

Use Processes and a ~60-second Performance view to find the apps consuming CPU, disk, or memory.

Fix · Degraded performance

Windows Update checks

Install pending OS patches that fix known performance bugs and resource leaks.

Fix · Degraded performance

Free disk space

Clear unused files so the volume has headroom for paging, updates, and temp files.

Fix · Degraded performance

Defrag (HDD)

On hard disks, run Optimize/Defragment. Skip routine defrag on SSDs — they use TRIM/optimize instead.

Fix · Degraded performance

Laptop power source

Seat the charger firmly — on battery or a weak adapter, Windows may throttle the CPU.

Fix · Degraded performance

Antivirus scan

Run a full scan when Task Manager shows unexplained high CPU or disk use from malware.

Problem

Low memory warnings

Windows warns that memory is nearly full — apps may freeze, crash, or refuse to open while RAM pressure is high.

If the question asks for a short-term fix and RAM is already near 100%, reboot. That ends every process and frees memory immediately. Closing heavy apps in Task Manager is the same idea if you can still work. Disable startup items, OS patches, and defrag are longer-term or the wrong resource (disk, not RAM).

Fix · Low memory

Close memory-heavy apps

Sort Task Manager by Memory, save work, then close or restart the programs using the most RAM.

Fix · Low memory

Virtual memory (paging file)

Review the paging file under System > About > Advanced system settings > Performance Settings > Virtual Memory.

Problem

Frequent shutdowns

The system powers off or stops without a scheduled shutdown — often hardware faults, corrupted system files, or malware.

Fix · Frequent shutdowns

Full hardware diagnostics

Test motherboard, CPU, and RAM with UEFI/BIOS or vendor diagnostic tools.

Fix · Frequent shutdowns

Windows Memory Diagnostics

Reboot into the built-in RAM test when random power-offs suggest memory errors.

Fix · Frequent shutdowns

System File Checker (sfc)

Run sfc /scannow to repair corrupted Windows files that can force unexpected stops.

Fix · Frequent shutdowns

Anti-malware scan

Scan for malware that can crash services or force the machine offline.

Problem

System instability

Random crashes, freezes, or reboots with no single app clearly to blame.

Fix · System instability

Full hardware diagnostics

Stress-test CPU, RAM, and related hardware when there is no clear software cause.

Fix · System instability

Windows Memory Diagnostics

Run the built-in RAM test when freezes or BSODs look memory-related.

Fix · System instability

System File Checker (sfc)

Scan and repair corrupted Windows system files with sfc /scannow.

Fix · System instability

Anti-malware scan

Scan for malware that injects into processes or tampers with system files.

Problem

Time drift

The clock slowly loses accuracy because of unreliable hardware timekeeping — which can break auth, certificates, and sync.

HTTPS certificates are only valid between a start date and an end date. The browser compares those dates to this PC’s clock. If the laptop clock is wrong, every HTTPS site can throw a security alert even though the sites are fine. A phone or another PC with a correct clock will not show the error. That “all HTTPS, this device only” pattern is time/date — not a bad subnet mask, stale AV signatures, or the phone’s OS version.

Fix · Time drift

Set time automatically

In Settings > Time & Language > Date & Time, enable automatic time (and DST) so Windows syncs to time servers, or sync manually.

Part C

Services, applications, and peripherals

When services fail, apps crash, USB endpoints max out, or domain profiles load slowly.

Problem

Services not starting

Windows or third-party services fail to start, leaving features offline until drivers, permissions, or dependencies are fixed.

Fix · Services

Device Manager

Check device status, then update, roll back, or replace drivers that block related services.

Fix · Services

services.msc

Start the service manually, adjust the log-on account, and verify dependencies in the Services app.

Fix · Services

sfc /scannow

Repair corrupted built-in Windows service binaries. For third-party app services, reinstall the app with admin rights.

Problem

Applications crashing

One or more programs close unexpectedly, hang, or fail to stay open during normal use.

Fix · App crashes

Event Viewer / Reliability Monitor

Inspect crash logs and reliability history to identify the failing module or recent change.

Fix · App crashes

Reinstall the application

Repair or reinstall the failing app after logs point to a corrupted install.

Problem

USB controller resource warnings

Connecting a device exceeds the USB controller’s available endpoints, so Windows warns or the device misbehaves.

Fix · USB warnings

Move to another USB port

Disconnect the device and plug it into a different port or controller to free endpoints.

Fix · USB warnings

Balance USB 2.0 / 3.0

Keep USB 2.0 devices on USB 2.0 controllers and USB 3.0 devices on USB 3.0 controllers to spread endpoint load.

Problem

Slow profile load

Sign-in takes a long time, usually from network latency or WAN congestion while syncing a roaming profile to a domain controller.

A corrupted or temporary profile looks different: the user reaches the desktop quickly, but it is a default wallpaper and Documents / My Documents is empty. Rebuild it: rename C:\Users\username, delete that profile’s SID under HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ProfileList, then have them sign in again so Windows creates a clean profile. Copy files back from the renamed folder. Safe Mode, making them an Administrator, or an OS upgrade will not fix this.

Fix · Slow profile

Repair / optimize domain controllers

Domain admins fix or optimize local DCs and profile sync paths so roaming profiles load without WAN bottlenecks.
