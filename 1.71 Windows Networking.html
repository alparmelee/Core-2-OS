Part A

Domain, shares, and printers

How PCs join a network, and how folders, printers, and drives are shared.

Domain joined vs. workgroup

↳ System Properties (sysdm.cpl)

Compares centralized authentication using Active Directory and domain controllers against decentralized peer-to-peer administrative groups.

Domain - Centralized access control, Active Directory integration, Scalable across many devices

Workgroup - Limited to small networks, Manual Configuration per device, Local user-based access control

  • Active Directory
  • Workgroup
Find it
  1. Press Win + R, type sysdm.cpl, press Enter.
  2. Open the Computer Name tab (shows Workgroup or Domain).

Shared resources
  • NTFS permissions
  • Share permissions
Network assets like folders and devices made accessible across the network using NTFS and share permissions.

Advanced File Sharing
Control Panel:
Network and Internet (In category view) > Network and Sharing Center > Change advanced sharing settings
Network Sharing Center (an icon view) > Change advanced sharing settings

Settings:
Network and internet > Advanced network settings > Advanced sharing settings

  • Network discovery allows a Windows system to locate and be located by other devices on a local network.

  • File and printer sharing enables remote network users to access designated folders and attached printers on the machine.

  • Password-protected sharing controls authentication by requiring remote users to enter a valid local account password to access shared resources.

    Subnet Mask

    DNS settings

    ↳ IPv4 Properties → Preferred / Alternate DNS server

    Subnet mask

    ↳ IPv4 Properties → Subnet mask

    A 32-bit mask that separates an IP address into its network ID and host ID portions.

    Find it on your PC
    1. In TCP/IPv4 Properties (Use the following IP address), screenshot the Subnet mask field.
    2. If DHCP is on, switch temporarily to “Use the following…” to reveal the field for a screenshot (don’t Apply if you only need a photo).

    Gateway

    ↳ IPv4 Properties → Default gateway

    The IP address of the local router interface that forwards out-of-subnet traffic to external networks.

    Find it on your PC
    1. In TCP/IPv4 Properties, screenshot the Default gateway field.

    Public network vs private network

    ↳ Settings → Network & Internet → [Wi-Fi/Ethernet] → network properties → Network profile type

    Network location profiles that automatically adjust firewall rules, hiding the device on public Wi-Fi or enabling discovery on trusted private networks.

    • Public
    The PC can't be used for file and printer sharing
    Used for untrusted networks, such as a Wi-Fi network at a coffee shop
    The PC remains hidden from other devices on the network
    • Private
    Used for trusted networks, such as home or work networks
    Enables the PC to become discoverable to other devices on the network
    Enables the PC to be used for file and printer sharing
    Access to a configuration interface used for modifying public/private network profile settings
    1. Windows Control Panel (category view) > View network status and tasks > Change advanced sharing settings
    2. Windows Control Panel (icon view) > Network and Sharing Center > Change advanced sharing settings
