Router, Wireless, and Firewall Settings

SOHO router hardening, wireless security, and firewall configuration for home and small office networks.

Part A

Router settings

Core SOHO router configuration for security, access control, and management.

Change default passwords

Access points ship with publicly known default credentials. Change the default admin password immediately to prevent unauthorized users from taking full administrative control of the device.

IP filtering

Restrict or grant network access by defining specific IP address ranges.

  • Allow list — block all traffic except approved IP addresses.
  • Deny list — block specific bad IP addresses.

Firmware updates

Maintain SOHO appliances by regularly applying manufacturer updates. Installing the latest firmware patches security vulnerabilities, fixes bugs, and adds missing features.

Content filtering

Inspect network traffic by URL or website category. Use content filters to enforce corporate policies, manage parental controls/NSFW content, prevent sensitive data leaks, and stop malicious software via integrated anti-virus features.

Physical placement / secure locations

Lock physical routers, switches, and servers in a secure room to prevent physical tampering. Mount wireless access points high (such as above ceiling tiles) to maximize coverage — keeping in mind that hard-to-reach locations make power cycling more difficult.

Universal Plug and Play (UPnP)

UPnP permits devices and internal applications to open inbound firewall ports automatically without administrator approval.

Disable UPnP as a best practice unless an application strictly requires it.

Screened subnet

Formerly DMZ — Demilitarized Zone

Place public-facing resources (like web servers) in a screened subnet between the internet and the internal network. Creates an isolated security layer so external access to public services doesn’t compromise private internal systems.

Configure secure management access

Enforce strong authentication credentials and multi-factor authentication for administrative logins. Restrict management connections to local LAN IPs only and disable remote WAN management access completely.

Part B

Wireless specific

SSID, encryption, and guest network configuration.

Changing the service set identifier (SSID)

Replace default factory network names (such as “NETGEAR” or “LINKSYS”) with a non-obvious identifier to avoid signaling your equipment type to outsiders.

Disabling SSID broadcast

Hiding an SSID stops the router from broadcasting its name publicly. However, this only relies on security through obscurity — wireless analysis tools easily discover hidden SSIDs.

Not a real security control. Always use strong encryption instead of relying on a hidden SSID.

Encryption settings

Choose an appropriate wireless encryption standard:

  • Open system — unencrypted; no password required.
  • WPA2/WPA3-Personal (PSK) — protects traffic using a shared 256-bit key among all users.
  • WPA2/WPA3-Enterprise (802.1X) — authenticates each user individually through a backend server (e.g., RADIUS or LDAP).

Configuring guest access

Enable isolated guest networks to keep visitors off the primary LAN, or use guest networks to segregate IoT devices and lab environments. Always protect guest networks using WPA2 or WPA3 encryption.

Part C

Firewall settings

Port control and inbound traffic management.

Disabling unused ports

Administratively turn off unused physical switch ports in open areas (like conference rooms or break rooms) to stop unauthorized physical hookups. Alternatively, deploy Network Access Control (802.1X NAC) to block network traffic until a device authenticates.

Port forwarding / mapping

Destination NAT — Static NAT

Configure Destination NAT (Static NAT) to permanently direct external inbound traffic from a public IP and port to an internal server’s private IP and port. Provides persistent 24/7 internet access to internally hosted applications like web servers, game servers, or security systems.
