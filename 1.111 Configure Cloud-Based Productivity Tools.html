Part A

Mail, storage, and sync

Hosted email, cloud file repos, and the rules that keep folders in step with the cloud.

Email Systems

Outlook → Mail flow (MX records)

Cloud-based communication infrastructure (e.g., Exchange Online, Gmail) providing business email hosting, domain routing, MX record configuration, and mailbox setup.

MX records tell the internet which host accepts mail for the domain. Until those DNS records point at the cloud tenant, mailboxes exist but inbound mail never arrives.

Practice in the 1.11 interactive lab — open Outlook and check Mail flow (MX records).

Cloud Storage

Open OneDrive

Centralized online repositories (e.g., OneDrive, Google Drive) enabling secure file storage, file sharing permissions, version control, and cloud accessibility.

Users get the same files from a browser, phone, or synced PC. Sharing is permission-based (view vs edit, link vs named people), and version history is how you undo a bad overwrite.

Practice in the 1.11 interactive lab — open OneDrive from the waffle menu.

Sync and Folder Settings

OneDrive → Sync settings

Configuration rules controlling how local directories synchronize with cloud storage, including selective sync, bandwidth limits, and sync options.

Selective sync keeps huge folders off a small laptop disk. Bandwidth caps stop a first sync from saturating the office WAN. Files On-Demand can show placeholders until someone opens the file.

Practice in the 1.11 interactive lab — open OneDrive Sync settings.

Part C

Identity and licensing

The admin-center work that makes the suite actually usable for the company.

Identity Synchronization

Admin Center → Identity

Process of mirroring local Active Directory users and credentials to cloud identity providers (e.g., Entra ID Connect) for single sign-on (SSO) and hybrid user access.

Users keep one password. On-prem AD remains the source; a sync tool (Entra ID Connect / Azure AD Connect) copies accounts to the cloud so Outlook, Teams, and OneDrive honor the same identity.

Practice in the 1.11 interactive lab — open Admin Center → Identity.

Licensing Assignment

Admin Center → Licenses

Administrative process of provisioning, purchasing, and revoking subscription licenses (e.g., Microsoft 365, Google Workspace) to managed user accounts.

A mailbox or Teams account that looks “broken” is often just unlicensed. Revoke the seat when someone leaves so you are not paying for an empty account.

Practice in the 1.11 interactive lab — open Admin Center → Licenses.
