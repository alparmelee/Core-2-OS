Part A

Operating systems

An OS sits between you, your apps, and the hardware — scheduling work, managing memory, and making devices usable.

Operating System

An operating system is foundational system software that manages a computer’s hardware and software resources while acting as an intermediary between the user, applications, and physical components.

Think of it as the layer that turns raw CPU, RAM, storage, and devices into a usable computer.

Windows

Major market presence. Many different versions, such as Windows 10, Windows 11, and Windows Server.

Advantages

Large industry support, a broad selection of OS options, and a wide variety of software support.

Disadvantages

A big target for security exploitation, and large hardware support can create challenging integration exercises.

Linux

Free Unix-compatible software system. Unix-like, but not Unix. Many different distributions such as Ubuntu, Debian, Red Hat, and Fedora.

Advantages

Free, works on a wide variety of hardware, and has a passionate and active community.

Disadvantages

Limited driver support (especially on laptops) and limited support options compared with commercial platforms.

macOS

A desktop OS running on Apple hardware.

Advantages

Ease of use, high compatibility within Apple’s ecosystem, and fewer security concerns relative to broader PC targets.

Disadvantages

Requires Apple hardware, less industry support than the PC platform, and higher initial hardware cost.

Chrome OS

Google’s operating system, based on the Linux kernel. It centers around the Chrome web browser, and most apps are web-based. Many manufacturers make Chromebooks, and devices are relatively less expensive.

Trade-off

It relies on the cloud for many apps and services — connectivity matters.

iPadOS

Operating system for Apple’s iPad tablets and a variant of Apple’s phone OS (iOS).

  • Desktop-class Safari
  • Sidecar (second monitor)
  • Keyboard support
  • Multitasking

iOS

Apple iOS, used for Apple iPhones, is based on Unix. It is closed source (no public access to the source code) and exclusive to Apple products.

iOS apps are developed with Apple’s SDK on macOS, must be approved by Apple before release, and are available to users in the Apple App Store.

Android

Google Android is backed by the Open Handset Alliance. It is an open-source OS based on Linux and is supported on many manufacturers’ devices.

Android apps are developed on Windows, macOS, and Linux with the Android SDK. Apps are available from Google Play and also from third-party sites like the Amazon Appstore.

Part B

File systems

How an OS names, stores, and finds files on disks, SSDs, and removable media.

File Systems

A file system is the method and data structure an operating system uses to organize, name, store, and retrieve files on a storage device.

Without a file system, data on a drive would be an unorganized stream of bytes with no way to identify where one file ends and the next begins.

New Technology File System (NTFS)

Windows default for most modern volumes

Extensive improvements over FAT32: quotas, file compression, encryption, symbolic links, large file support, security, and recoverability.

Not very compatible across operating systems. Many OSes will read NTFS but not write. Some have limited write functionality to an NTFS file system.

Resilient File System (ReFS)

The future of Windows file systems

An update to NTFS concepts for Server 2012 and later, with limited support in Windows 8.1 and later. Built for huge storage requirements and very large drives and storage arrays.

  • Constant data availability
  • Self-repairing
  • Ongoing integrity checks
  • No more chkdsk!
  • RAID-like redundancy

Measured integration, updates, and improvements are ongoing.

File Allocation Table 32 (FAT32)

FAT (File Allocation Table) is one of the first PC-based file systems (circa 1980).

FAT32 supports larger volume sizes (up to about 2 terabytes) and a maximum file size of 4 gigabytes.

Fourth extended filesystem (ext4)

Fourth extended file system — an update to ext3. Commonly seen in Linux and Android OS.

Extended filesystem (XFS)

High-performance file system for Linux, supported in most Linux distributions. Designed for scalability, large-scale computing, and high-speed processing.

  • Enterprise features
  • Large file system sizes
  • Built-in journaling
  • Minimal fragmentation

Apple File System (APFS)

Added in macOS High Sierra (10.12.4). Also included with iOS and iPadOS. Optimized for solid-state storage.

  • Encryption
  • Snapshots
  • Increased data integrity

Extensible File Allocation Table (exFAT)

Microsoft flash drive file system. Files can be larger than 4 gigabytes. Compatible across many operating systems — Windows, Linux, and macOS.

Part C

Updates, EOL, and compatibility

How long platforms are supported, how updates arrive, and what moves cleanly between OSes.

End-of-life (EOL)

Vendor-specific limitations. Different companies set their own EOL policies for when a product stops receiving updates and support.

Update limitations

iOS, Android, and Windows check and prompt for updates. Chrome OS will update automatically.

Compatibility concerns between operating systems

Some movies and music can be shared. However, there is no direct application compatibility. Fortunately, many apps have been built to run on different OSes.

Some data files can be moved across systems. Web-based apps have strong potential for cross-platform use.
