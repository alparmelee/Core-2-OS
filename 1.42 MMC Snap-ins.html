Overview

Microsoft Management Console

Snap-ins are the tools you load into MMC (mmc.exe) — or open directly with their .msc file.

MMC snap-ins

Microsoft Management Console

Administrative tools that plug into MMC so you can manage Windows from a console. Most can also be launched alone by running their .msc filename.

  • eventvwr.msc
  • diskmgmt.msc
  • taskschd.msc
  • devmgmt.msc
  • certmgr.msc
  • lusrmgr.msc
  • perfmon.msc
  • gpedit.msc
Part A

Event Viewer

Monitor system health and troubleshoot issues by managing event logs.

Event Viewer

eventvwr.msc

A utility used to monitor system health and troubleshoot issues by managing event logs.

Application & System Logs

Categorized into Information (normal operations), Warning (non-critical issues), and Error (serious problems) events.

  • Information
  • Warning
  • Error

Security Log

Records audit events reporting the Success or Failure of security-related actions.

  • Success
  • Failure
Part B

Storage and scheduling

Manage disks/volumes and automate work with Task Scheduler.

Disk Management

diskmgmt.msc

The standalone graphical utility designed specifically for viewing, formatting, partitioning, and managing storage devices and volumes.

Formatting or deleting a volume can erase data — keep a backup before making disk changes.

Task Scheduler

taskschd.msc

An administrative tool used to automate and schedule the execution of programs, scripts, or tasks at pre-defined times, intervals, or triggers.

Part C

Hardware, certificates, and accounts

Drivers, digital certificates, and local users/groups.

Device Manager

devmgmt.msc

The primary graphical interface used to view, configure, update, enable/disable, and troubleshoot installed hardware components and their associated drivers.

Certificate Manager

certmgr.msc

An MMC snap-in used to view, import, export, and delete digital certificates and key pairs for the currently logged-in user account.

Local Users and Groups

lusrmgr.msc

An MMC snap-in used to create, remove, and manage local user accounts and group memberships (included in Windows Pro, Enterprise, and Education editions, but omitted from Home editions).

Not available in Windows Home — use Settings or net user / net localgroup there instead.
Part D

Performance and policy

Long-term metrics and local computer/user policy settings.

Performance Monitor

perfmon.exe / perfmon.msc

A system monitoring utility used to analyze program and system performance in real time and collect long-term diagnostic logs using Data Collector Sets.

  • Real-time counters
  • Data Collector Sets

Local Group Policy Editor

gpedit.msc

An administrative snap-in used to configure policies that control operating system behaviors, security parameters, user rights, and computer settings.
