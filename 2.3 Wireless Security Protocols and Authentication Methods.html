Part A

Wireless security protocols

Encryption standards that protect data traveling over Wi-Fi — from legacy bridges to modern protections.

Wi-Fi Protected Access 2 (WPA2)

Introduced 2004 — legacy standard

WPA2 is a legacy wireless security protocol introduced in 2004 that uses AES encryption to secure Wi-Fi networks.

Still widely deployed, but WPA3 is the current recommended standard.

WPA3

Introduced 2018 — modern standard

WPA3 is the modern wireless security standard that provides stronger AES encryption options, improved key exchange security, and individual encryption even on open networks.

WPA3

Stronger key exchange, per-device encryption on open networks, forward secrecy.

WPA2

Older, widely supported, but lacks WPA3’s protections against offline dictionary attacks.

Temporal Key Integrity Protocol (TKIP)

WPA bridge from WEP

TKIP is an older encryption protocol designed for WPA as a temporary bridge to replace WEP without requiring new hardware.

Legacy only. TKIP is deprecated — use AES with WPA2 or WPA3 instead.

Advanced Encryption Standard (AES)

CCMP — used by WPA2 and WPA3

AES is a highly secure symmetric encryption algorithm used by WPA2 and WPA3 that offers significantly stronger protection than TKIP at the cost of higher CPU processing requirements.

AES

Industry-standard strong encryption. Required for modern WPA2/WPA3 deployments.

TKIP

Weaker, older. Only existed to extend hardware life after WEP was broken.

Part B

Authentication methods

Protocols and practices that verify who is connecting — on Wi-Fi, VPNs, and network infrastructure.

Remote Authentication Dial-in User Service (RADIUS)

AAA — Authentication, Authorization, Accounting

RADIUS is a widely supported AAA protocol used in enterprise networks to centralize user authentication across 802.1X Wi-Fi, VPNs, and network infrastructure.

Terminal Access Controller Access-Control System (TACACS+)

Cisco-developed — open standard

TACACS+ is an open-standard remote authentication protocol created as an upgraded alternative to TACACS for managing administrative access to network devices.

RADIUS

User/network access — Wi-Fi (802.1X), VPN, dial-in. Combines auth and accounting.

TACACS+

Device administration — separates authentication, authorization, and accounting. Common on routers/switches.

Kerberos

Ticket-based SSO

Kerberos is a ticket-based network authentication protocol that enables single sign-on (SSO) and mutual authentication between clients and servers to prevent replay attacks.

Multifactor authentication

MFA — two or more factors

Multifactor authentication verifies user identity by requiring two or more distinct verification credentials, such as passwords and security tokens, before granting wireless network access.
