Part A

Hardware and firmware prerequisites

Security chips and modern firmware that Windows — especially Windows 11 — depends on.

Trusted Platform Module (TPM)

TPM 2.0 required for Windows 11

A dedicated hardware-based security microchip that securely stores cryptographic keys, credentials, and encryption measurements used by features like BitLocker.

Windows 11: specifically requires TPM 2.0.

Unified Extensible Firmware Interface (UEFI)

Replaced legacy BIOS

Modern motherboard system firmware that replaced legacy BIOS, offering faster boot times, support for large drives, and enhanced startup security features like Secure Boot.

Part B

Windows 10 editions

From retail home PCs to large enterprise deployments.

Windows 10 Home

Consumer / retail

Designed for home users and purchased at a retail store. Integration with Microsoft account and OneDrive backup. Includes Windows Defender. You can use Cortana to talk to your OS.

  • Microsoft account
  • OneDrive backup
  • Windows Defender
  • Cortana

Windows 10 Pro

Business version

The business version of Windows with additional management features.

  • Remote Desktop host — remotely control each computer
  • BitLocker — full disk encryption (FDE)
  • Join a Windows domain
  • Group Policy management

Windows 10 Pro for Workstations

High-end desktops

An edition for high-end desktops with enhanced performance and storage options.

  • Up to 4 physical CPUs
  • Up to 6 TB RAM
  • ReFS (Resilient File System)
  • Same ReFS support as Windows Server

Windows 10 Enterprise

Large implementations

Built for large implementations with volume licensing.

  • AppLocker — control what applications can run
  • BranchCache — remote site file caching
  • Granular User Experience (UX) control — define the user environment
Useful for kiosk and workstation customization.
Part C

Windows 11 editions

The same Home / Pro / Enterprise ladder, with Windows 11–specific features.

Windows 11 Home

Consumer version

Designed for home use. Integrated with Microsoft accounts. Can be installed with a local account. Limited management functionality — no support for Active Directory.

Includes Device Encryption — a consumer version of full disk encryption. Stores the recovery information in the user’s Microsoft account.

Windows 11 Pro

Designed for business

Large-scale system management. Integrates with Active Directory (Microsoft’s directory services).

  • BitLocker (FDE)
  • Active Directory
  • Microsoft Hyper-V
  • Integrated virtualization

Windows 11 Enterprise

Large company deployments

Built for large company deployments with volume licensing and server-style management features.

  • Volume licensing
  • MDM & MAM
  • Device management
  • ReFS support
Part D

Special editions

Regional variants you may still see on the exam.

N Versions

Windows editions for Europe

The result of antitrust investigations by the European Commission. No Windows Media Player included. Media features can be added to Windows later.

Part E

Features that differ by edition

Networking model, UI, remote access, memory caps, encryption, and Group Policy.

Domain vs Workgroup

Domain

Centralized network management. User accounts and security policies are managed by a central server (Domain Controller).

Workgroup

Peer-to-peer model. Every computer manages its own local user accounts and security settings independently.

Desktop styles / user interface

The visual presentation, layouts, Start menu behaviors, and taskbar configurations provided by different Windows versions or editions.

Example: centered taskbar alignment in Windows 11 vs. left-aligned layout in Windows 10.

Availability of Remote Desktop Protocol (RDP)

RDP allows a user to remotely control a PC over a network connection.

  • All editions can act as an RDP client (connecting to other PCs).
  • Only Pro, Enterprise, and Education can act as an RDP host (receiving incoming connections).

Random-access memory (RAM) support limitations

Physical memory caps built into specific Windows editions and architectures.

  • 32-bit Windows → 4 GB max
  • Home → up to 128 GB
  • Pro → up to 2 TB

BitLocker

Full-disk encryption (FDE)

A full-disk encryption security feature included in Windows Pro, Enterprise, and Education editions that protects drive contents by scrambling data when the system is offline or powered down.

Home uses a lighter Device Encryption model (recovery key tied to the Microsoft account).

gpedit.msc

Local Group Policy Editor

The Local Group Policy Editor console, available in Pro and higher editions, used by administrators to configure system-wide security policies, user restrictions, and OS configurations on a local machine.

Part F

Upgrade paths

Two ways to move to a newer Windows version or edition.

In-place upgrade

Updating an existing Windows installation to a newer version or edition while keeping all existing files, settings, and installed applications intact.

Clean install

Completely wiping the storage drive (formatting) and installing a fresh copy of the operating system from scratch, requiring manually restoring files and reinstalling software.
