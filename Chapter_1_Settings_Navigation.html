Worth recognizing too

These are the ones where the exam is genuinely likely to describe the alternate route instead of the one you memorized. Open only to check yourself. Drill them in the Recognize trainer.

Internet Options & Proxy

1.61 / 1.71recognize
Know inetcpl.cpl → Connections tab → LAN settings for Proxy
Also shows up as
  • Control Panel → Internet Options (same window, reached without Run)
  • Settings → Network & Internet → Proxy (Win10 wording: "Network & Internet"; Win11: "Network & internet")

Firewall, allow an app, advanced settings

1.71recognize

Also shows up as
  • Control Panel → System and Security → Windows Defender Firewall → same two options

macOS

This won't show up as a click-through simulation, just multiple-choice recognition. Skim it, don't drill it.

System Settings pages: Apple ID, General, Displays, Network, Printers & Scanners, Privacy & Security, Accessibility.

Shortcuts: Spotlight ⌘+Space, Mission Control Control+↑, Force Quit ⌘+Option+Esc.

Know by name only: Time Machine, Disk Utility, Terminal, Keychain Access — launched from Spotlight/Launchpad.

Cut for time

Skipped, low-yield items

Recognize the name if you see it, but not worth a dedicated drill: Indexing Options, Mail applet, Sound applet, Ease of Access, Certificate Manager (certmgr.msc), Administrative Tools / Windows Tools folder naming, metered connections toggle, Power Options' System Settings vs. Advanced sub-pages, Performance Monitor's .exe vs .msc distinction. All of these are single Control-Panel-style lookups with no real "recognize the alternate" trap — if it comes up, it'll be a straightforward "where do you find X" question.
