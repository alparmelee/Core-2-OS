Part A

Specific tool switches & parameters

Flags that change how common Windows commands behave on the exam.

ipconfig /release
ipconfig /renew DHCP refresh

ipconfig /release and ipconfig /renew

DHCP lease refresh

Commands used to refresh DHCP configurations for network adapters.

ipconfig /release drops the current DHCP address; ipconfig /renew requests a new lease from the DHCP server.

  • /release
  • /renew
  • DHCP
dir /s *.exe recurse

dir /s

dir /s [pattern]

The /s flag recurses through subdirectories when listing files (for example, dir /s *.exe).

format /q quick format

format /q

quick format

The quick format option removes file system references without performing a full overwrite of every sector on the volume.

Faster than a full format, but less thorough for wiping recoverable data.
rmdir /s /q folder delete

rmdir /s and rmdir /q

rd /s /q

Used in folder-deletion scenarios: /s removes directory trees (the folder and everything inside), and /q enables quiet mode (no confirmation prompts).

  • /s — tree
  • /q — quiet
sfc /scannow system files

sfc — system file replacement

System File Checker

SFC specifically replaces incorrect or corrupted system file versions with correct Microsoft versions from a known-good store (often the component store / WinSxS).

Common form: sfc /scannow (run elevated).
Part B

Command variations & navigation shortcuts

Equivalent syntax and directory shortcuts you are expected to recognize.

cd \ root of drive

cd \

change to drive root

Changes the working directory directly to the root directory of the current drive (for example, from C:\Users\Andre\Documents to C:\).

help dir
dir /? help syntax

help [command] vs [command] /?

equivalent help forms

help [command] is a valid alternative syntax for displaying command-specific help, alongside [command] /?.

Example: help ipconfig and ipconfig /? both show usage for ipconfig.

md
mkdir aliases

md vs mkdir

make directory

There is no functional difference between md and mkdir in Windows — both create directories.

G:
cd G: drive change

Changing directory to a letter drive (e.g. G:)

CMD vs PowerShell

To switch to another drive letter in Command Prompt (cmd.exe), type the drive alone — for example G: — not cd G:.

cd G: (or Set-Location G:) is how you change to that drive in PowerShell. In classic CMD, cd G: does not switch you onto the G: drive the way students often expect.

Remember for the exam: cd G: works as a drive change in PowerShell; in CMD use G: by itself (and cd \ or cd folder for paths on the current drive).
Part C

Troubleshooting & administrative scenarios

Loopback testing, elevation failures, and account auditing with net user.

ping 127.0.0.1 loopback

Loopback testing (ping 127.0.0.1)

IPv4 loopback

Using the loopback address verifies that the local TCP/IP stack is functioning properly — replies mean the network stack on this PC is alive, independent of the NIC or remote network.

  • 127.0.0.1
  • ::1 (IPv6)
diskpart
Access is denied UAC / admin

Elevation issues

Access is denied

Encountering an “Access is denied” error when running diskpart is typically caused by failing to launch the terminal with administrative privileges.

Fix: open Command Prompt or PowerShell with Run as administrator, then retry diskpart.
net user username account audit

net user [username] — account auditing

net user Andre

Running net user with a specific username reveals account status details such as lockout/disabled state, last logon time, and password requirements.

net user alone lists local accounts; net user name shows that account’s detailed properties.
